# Online Vaccine Tracking System

## Project Description
The Online Vaccine Tracking System is a software application that helps users track vaccine availability, vaccination status, and upcoming vaccination schedules.

## Objectives
- To maintain vaccination records.
- To track vaccine availability.
- To help users view their vaccination status.
- To provide information about upcoming vaccine doses.

## Main Modules
1. User Registration and Login
2. Vaccine Availability
3. Vaccination Records
4. Dose and Appointment Tracking
5. Admin Management

## Version Control
Git is used to track changes and maintain different versions of the project.
## New Feature: Vaccine Status Tracking
Users can check whether their vaccine doses are completed, pending, or upcoming.
